avere una fonte in questi documenti**: se una frase in pagina non è
coperta qui, o si aggiorna il documento o si toglie la frase.

Regole di scope, valide per tutto il repo:

- Questo repository contiene la **piattaforma di lancio**, non il prodotto:
  niente AI reale, niente integrazione WhatsApp funzionante. Le demo sul
  sito sono conversazioni scriptate e dichiarate come simulazioni.
- Le funzionalità in roadmap si comunicano al futuro, mai come disponibili.
- I prezzi sono ipotesi: sul sito compaiono come tariffa di lancio.
